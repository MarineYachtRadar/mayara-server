Garmin radar setup

GMR HD, xHD, xHD2 and xHD3, Fantom and Fantom Pro.

What you need

  • An address in the 172.16.0.0/12 range on the Mayara machine
  • A wired Ethernet connection to the radar
  • A switch that passes multicast (every unmanaged switch does)
The subnet is mandatory

Garmin radars communicate on 172.16.0.0/12. The machine running Mayara must have an address between 172.16.x.x and 172.31.x.x, or the radar is never detected. The Interfaces button on Mayara's radar list shows which interfaces Mayara is listening on for each brand.

Recommended configuration

  • Address: 172.16.1.2, or any unused 172.16.x.x
  • Netmask: 255.240.0.0
  • No default gateway required
WiFi will not work for the radar

Garmin spoke data is multicast, and WiFi carries multicast at the base rate with no retransmissions. The result is a picture full of gaps and an access point whose airtime is consumed for every other user. Wire the radar to Mayara, then view Mayara over WiFi. The full explanation.

Model detection is automatic, from the radar's capability bitmap and its CDM heartbeat.

Dual range

xHD2, xHD3, Fantom and Fantom Pro can run two range windows at once. Mayara lists each as its own radar, Range A and Range B.

MotionScope (Doppler)

Fantom and Fantom Pro colour-code approaching and receding targets. The radar does this processing internally, but possibly with help from a Garmin chartplotter sending it heading data.

We do not know yet whether that help is required. Mayara does not send Garmin heading packets onto the Ethernet, so Doppler may turn out to be unavailable without a chartplotter. If you find that it is, please tell us.

Troubleshooting

Radar not detected

  • Confirm the Mayara machine has an address in 172.16.0.0/12, for example 172.16.3.150.
  • Open Interfaces on the radar list to see whether Mayara has a Garmin listener on any interface.
  • Confirm the Ethernet cable is connected and the radar has power.
  • Name the interface if the machine has several: mayara-server -i eth0

Wrong model detected

Detection relies on the capability bitmap the radar broadcasts. If the name looks wrong, please report your radar model together with the output of mayara-server -vv and/or the Network Diagnostics download from the radar list.
