Koden radar setup

MDS-R series radars connected through a RADARpc Ethernet control box (MDS-5R, MDS-6R, MDS-11R).

Untested

Koden support has not been tested against a real radar at all. It is built entirely from second-hand knowledge of the protocol. If you have a Koden radar, please get in touch — we would very much like to hear what happens.

What you need

  • An Ethernet port on the MDS control box
  • The Mayara machine on the same subnet as the radar
  • UDP port 10001 open on the host firewall

Network requirements

Koden radars talk over UDP broadcast on port 10001, so the Mayara machine has to sit on the same subnet as the radar. The default radar address is usually in the 192.168.0.x range; give the Mayara machine a static address on that subnet.

WiFi will not work for the radar

Spoke data arrives as UDP broadcast, which WiFi handles exactly like multicast: base rate, no retransmissions, heavy airtime cost. Wire the radar to Mayara and view Mayara over WiFi. The full explanation.

The model is detected automatically from the radar's model-code response. As far as we know every control box speaks the same protocol, so any combination with an Ethernet port on the MDS box should work. We do not know which model code the newer MDS-11R control box reports — please tell us if you find out.

Koden radars driven by a Koden display unit appear not to use Ethernet at all for features such as dual display units, so those cannot be supported.

Controls

  • Power — standby or transmit
  • Gain — manual (0–100%) or auto
  • Sea clutter (STC) — manual (0–100%)
  • Rain clutter (FTC) — manual (0–100%)
  • Sea state — manual, auto or harbour
  • Interference rejection — off, low, medium, high
  • Target expansion — on or off
  • Scan speed — normal or fast
  • Tune — coarse (0–255), manual or auto
  • Fine tune — 0–15
  • Pulse width — short or long
  • Display timing — trigger delay for cable length (0–124)
  • No-transmit sector — blanking start and end angles
  • Park position — antenna park angle

Troubleshooting

Radar not detected

  • Confirm the machine and the radar are on the same subnet.
  • Confirm nothing is blocking UDP port 10001.
  • Limit detection to Koden to cut down the noise: mayara-server --brand koden

No spokes displayed

The radar has to be transmitting. Switch it from standby to transmit with the power control. A new radar may need a warm-up period first.
